Лабораторная работа по дисциплине «Компьютерная графика» №1



Программа реализует отображение окружности с центром в заданной точке, радиус которой можно изменять с клавиатуры в реальном времени.

![Демонстрация работы программы](<gif/demo.gif>)

Описание задачи

Необходимо разработать программу, которая строит на экране окружность заданного радиуса R с центром в точке (x, y) (все значения — целые). При каждом нажатии клавиши > радиус должен увеличиваться на заданную величину, при нажатии < — уменьшаться. Выход из программы — по нажатию клавиши ESC.



Программа реализована на языке

Язык	Интерпретатор/Версия	Среда разработки

Python	Python / 3.11.5		PyCharm Community Edition 2023.2.1



Используемые библиотеки

pygame — для создания окна, отображения графики и обработки событий клавиатуры



Описание возможностей

Программа позволяет визуализировать окружность с центром в середине экрана. Радиус окружности можно увеличивать и уменьшать прямо во время работы программы:



Shift + . (символ >) — увеличить радиус на 10 пикселей;



Shift + , (символ <) — уменьшить радиус на 10 пикселей;



ESC — выход из программы;



крестик окна — также завершает работу.



Установка и запуск

Установите зависимость:



pip install pygame



Сохраните код программы в файл main.py и запустите:



python main.py



Использование программы

Запустите программу — откроется окно с белым фоном и чёрной окружностью радиуса 100.



Нажимайте Shift + ., чтобы увеличить радиус.



Нажимайте Shift + ,, чтобы уменьшить радиус.



Нажмите ESC или закройте окно, чтобы выйти.
